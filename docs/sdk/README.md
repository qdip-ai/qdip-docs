# QDIP SDK — external developer documentation

[English quickstart](quickstart.en.md) | [Українська](quickstart.uk.md) | [Polski](quickstart.pl.md)

**Current supported documentation path:** QDIP SDK-02 remote Python Worker creates a `DecisionSpec`; the QDIP Gateway dispatches it to the managed Kernel; a separate backend application invokes the capability with `@qdip/client` SDK-03.

**Access is currently operator-assisted, not self-service.** A developer must obtain approved organization/application binding, Gateway URL, scoped registration and caller keys, and separately distributed signed-off/verified SDK artifacts. There is no publicly documented anonymous registration, unreviewed upload, automatic issuance, or production-ready third-party publication. Do **not** clone a private QDIP repository or require internal service URLs.

**Artifact reference versions:** SDK-02 wheel bundle `0.1.3`; SDK-03 `0.2.0`. Check the operator handoff and checksum for the actual pair. Older README snapshots may refer to different versions; use an agreed versioned handoff, not a filename guess.

For IP/security classification before releasing documentation or examples, see [publication safety](../security/publication-safety.md). No production, independent external E2E or scientific qualification is inferred from these guides.
